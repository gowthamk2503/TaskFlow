## AI Development Experience

I developed TaskFlow with the help of Google Antigravity and Code0. Antigravity helped me with the initial implementation, while I used Code0 to assist with reviewing code, debugging issues, testing, and Git/GitHub operations.

During development, I worked on the following tasks with Code0:

- **React components:** Reviewed the frontend components and improved code readability and organization.
- **API integration:** Worked through issues connecting the React frontend with the Express backend.
- **MongoDB integration:** Reviewed database operations for projects and tasks.
- **Testing and debugging:** Checked potential errors and reviewed test cases to improve application reliability.
- **Git and GitHub:** Used the Code0 terminal to manage changes, create commits, and push the project to GitHub.

I reviewed the suggested changes and checked the implementation against the project's requirements. This process helped me better understand how the frontend, backend, authentication, and database work together in a full-stack application.
