## AI Development Experience

I developed TaskFlow with the help of Google Antigravity and Code0. Antigravity helped with the initial implementation, while Code0 assisted me with code review, debugging, testing, and Git/GitHub operations.

During development, I used Code0 to work on the following tasks:

- **React Components:** Reviewed frontend components and improved code readability and organization.
- **API Integration:** Worked through issues connecting the React frontend with the Express backend.
- **MongoDB Integration:** Reviewed database operations for projects and tasks.
- **Testing and Debugging:** Investigated potential errors and reviewed test cases to improve application reliability.
- **Git and GitHub:** Used the Code0 terminal to manage changes, create commits, and push the project to GitHub.

I reviewed the suggested changes and checked the implementation against the project requirements. This experience helped me understand how the frontend, backend, authentication, and database work together in a full-stack MERN application.
